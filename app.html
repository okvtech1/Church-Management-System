Backup & Restore

How this works
  • A backup captures every record in every module — Members, Branches, and all 19 modules (Families, Attendance, Tithes & Offerings, Events, and the rest) — plus your Church Settings.
  • JSON backup is the one to use for restoring later — it preserves everything exactly and can be re-imported with the Restore button below.
  • CSV backup downloads a ZIP with one spreadsheet-friendly CSV per module — good for opening in Excel/Google Sheets or archiving, but restore it module-by-module using each module's own Import button instead of the Restore tool here.
  • Restoring adds the backed-up records back in — it does not erase what's already there, so it's safe to restore onto an account that already has some data (you may end up with duplicates if you restore the same backup twice).
  • Back up regularly, and always before making a large bulk change (like a CSV import) you might want to undo.

User Manual — Platform Admin

A quick reference for running the platform. For church-facing help, see each organization's own User Manual tab inside their dashboard.

Organizations

Every church that signs up appears here with its plan, billing cycle, subscription status, and live user/cell counts. Click an organization to change its subscription status, plan, or account status (Active/Suspended). Suspending an org blocks every user in it from logging in until you reactivate it.

Payments

Manual bank-transfer payment requests submitted by church admins land here for you to approve or reject. Approving one extends that organization's subscription by its billing cycle automatically. Payments made through a connected gateway (Paystack/Flutterwave/Remita) are verified and applied automatically and won't need manual review.

Send Message

Broadcasts an email to every organization admin at once — useful for platform-wide announcements (maintenance windows, new features, policy changes).

System Settings

Controls the platform-wide branding (app name, colors, logo shown before anyone logs in), business contact details, manual payment bank details, payment gateway keys, SMS/WhatsApp provider keys, and the Starter/Professional pricing tiers. Changes apply everywhere immediately — no redeploy needed.

Capacity monitoring

Each organization has its own spreadsheet with Google Sheets' 10,000,000-cell limit. The scheduled capacity check (set up per SETUP_GUIDE.md) flags any organization approaching that limit on the Organizations table, so you can reach out before it becomes a problem.
